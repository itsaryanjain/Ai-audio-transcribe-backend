## ✨ Features

| Feature | Description |
|---|---|
| 🎙️ **Speech to Text** | Accepts audio files and returns accurate transcriptions |
| 🌍 **Any Language** | Supports transcription in any spoken language |
| ⚡ **Fast API** | Lightweight REST API built with Spring Boot |
| 🔐 **Secure** | API keys and secrets stored safely as environment variables |
| 🌐 **CORS Enabled** | Configured to accept requests from the React frontend |
